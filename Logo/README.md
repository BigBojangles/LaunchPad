# LaunchPad logo pack (2026-10-08, app palette)

Matches the current app colors (Randy's APP-PALETTE.md). The old cream/orange palette is retired.

## Colors
- Light: background #F7F6F3, title #2E2A27, body #46423E, secondary #6E6863
- Dark: background #131313, title #F0F0F0, body #E1E1E1, secondary #969696
- Rocket: #B04614 on light, #DE7846 on dark (the only place rust shows up besides the New Project button)

## rocket/
- launchpad-rocket-light.svg / -dark.svg are the masters, transparent. PNGs from 64 to 2048.

## icon/
- LaunchPad.ico (16 to 256) and favicon.ico, using the #B04614 rocket.

## hero/
- launchpad-hero-light / -dark: 1600x900 cards that match the app home screen.
- launchpad-social-light / -dark: 1280x640 for GitHub Settings > Social preview.

## readme/
- Light and dark transparent headers for the top of the GitHub README, plus README-HEADER-SNIPPET.md to paste in.
