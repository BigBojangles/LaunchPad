# Changelog

## 1.0.2

LaunchPad rename release. Same fence/QEMU flow under the LaunchPad name, cream home UI with project bubbles, and installer path `%LOCALAPPDATA%\Programs\LaunchPad`.

## 1.0.1

Quality-of-life update. New first-run onboarding for Agent Bob users, plus a couple of extras on the home and project screens.

### Onboarding
- First launch asks **What kind of user are you?**
  - **Agent Bob assistant user** starts a 4-step guided setup
  - **I already use Grok Build** shows the short welcome, then home
- You can open that screen again later from home
- Agent Bob path: copy companion instructions, open Grok, create a first project (`my-checklist`), and see what to do next
- Step 4 includes the working loop and a starter prompt to copy into Agent Bob

### Existing projects
- **Add Project** lets you add a folder from anywhere
- **Open folder** opens that project in File Explorer

### Share
- **Share LaunchPad** on the home screen
- Copies a short message and the GitHub link
- Opens X, LinkedIn, or TikTok so you can paste and post

## 1.0.0

First public release.

- Windows desktop launcher for Grok Build projects
- New Project and Existing Project
- Quiet Grok Build install if it is missing
- Optional Desktop / Start Menu shortcuts in the installer
- Projects live in `%USERPROFILE%\Grok\Projects`
